⚙ Architecture Overview

🔧 The 6 MCP Tools

1

list_message_types

Returns the complete catalog of 13 MessageType constants with human-readable descriptions. Pure static data, no subprocess.

Input None
Output [{name, description}, ...]
2

list_backends

Enumerates all 4 backends, checks binary availability via LookPath, and detects capabilities through type assertion.

Input None
Output [{name, path, available, capabilities}, ...]
3

parse_line

Parses a raw JSONL line using a specific backend's parser. Invaluable for debugging wire format issues and testing parsers in isolation.

Input {backend, line}
Output Parsed agentrun.Message
4

explain_session

Shows the exact CLI arguments each backend would generate for a given session config. Reveals spawn, resume, and stream args side by side.

Input {model, cwd, options, env}
Output [{backend, spawn_args, resume_args, stream_args}]
5

run_turn

Executes a full agent turn. Validates all inputs through the security boundary, spawns the engine, captures messages + stderr + exit code.

Input {backend, prompt, model, cwd, options, env, timeout}
Output {messages[], exit_code, stderr, duration, error}
6

probe_backend

Lightweight health check: spawns a backend with a trivial prompt, verifies init emission, captures binary path, resume ID, and init metadata.

Input {backend}
Output {binary, spawns_ok, emits_init, init_meta, resume_id}

🔒 Security Boundary

Every tool call passes through a multi-layer security boundary before reaching the agentrun library.

CRITICAL

No Arbitrary Binary Execution

Backend names map to fixed binaries via switch dispatch. ACP binary configured server-side only via --acp-binary flag.

CRITICAL

Environment Variable Blocklist

14 blocked keys (PATH, HOME, LD_PRELOAD, DYLD_*, BASH_ENV, ENV) plus 5 sensitive patterns (_API_KEY, _SECRET, _TOKEN, _PASSWORD, _CREDENTIAL).

CRITICAL

CWD Scope + Symlink Resolution

filepath.EvalSymlinks on both CWD and workspace root prevents symlink-chain escape. Must be absolute, must exist, must be under --workspace.

HIGH

Options Allowlist

Only 6 safe options allowed. HITL and Mode are server-hardcoded (on / plan). Uses agentrun.Option* constants for compile-time safety.

HIGH

Credential Scrubbing

8 regex patterns detect sk-*, Bearer tokens, GitHub PATs, AWS keys, Slack tokens. All replaced with [REDACTED] before response.

HIGH

Bounded Stderr Collection

cappedWriter limits collection to 1MB during process lifetime. Output further truncated to 2KB with UTF-8-safe boundary.

HIGH

Concurrency Guard

Channel semaphore limits to 5 concurrent subprocess-heavy operations. Timeout clamped to 60-300s range.

HIGH

Required Workspace Flag

Server refuses to start without explicit --workspace. No default to shared /tmp.

⚡ Quick Start

Build

# From project root make mcp-build # builds bin/agentrun-mcp make mcp-qa # full quality gate (tidy + test + build)

Configure in Claude Code

{ "mcpServers": { "agentrun": { "command": "./bin/agentrun-mcp", "args": ["--workspace", "/tmp/agentrun-test"] } } }

Example Tool Calls

# Check which backends are installed list_backends # Debug a raw Codex JSONL line parse_line {"backend": "codex", "line": "{\"type\":\"error\",\"message\":\"rate limit\"}"} # See what CLI args each backend generates explain_session {"model": "claude-sonnet-4-5-20250514"} # Run a full turn with Claude run_turn {"backend": "claude", "prompt": "Say hello", "timeout": 30} # Health-check a backend probe_backend {"backend": "codex"}
